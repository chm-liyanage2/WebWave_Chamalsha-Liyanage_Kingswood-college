[ PROJECT OVERVIEW ]

VECTRA-86 is an interactive 1986 industrial vector cyberdeck simulator. 
It was built entirely from scratch using 100% pure HTML5, CSS3, and Vanilla JavaScript. 
Zero external libraries, game engines, or frameworks were used.

Key Features:
- Custom 1984 Formant Speech Synthesizer (VOX.SAM)
- Fully playable 1979-style vector arcade engine (ASTEROID.VEC)
- Real-time 3D wireframe satellite tracker (SATLINK.3D)
- Procedural sound design using the native Web Audio API
- Authentic P1/P3 Phosphor CRT shaders and hardware boot sequence
